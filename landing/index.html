Got Questions? We Have Answers

Install WPEPP (free from WordPress.org), navigate to WPEPP → Security, and enable Login Limiter. Set your preferred max failed attempts and lockout duration. IPs exceeding the limit are automatically blocked. No coding required.
With WPEPP Pro, enable Custom Login URL under Security. Enter your preferred slug (e.g., my-login). The default wp-login.php returns a 404, and your login page moves to the new custom URL — blocking automated attacks instantly.
Go to WPEPP → Security → AI Crawler Blocker. Toggle known AI bots on/off from a simple checklist. WPEPP auto-generates robots.txt rules and can block by user-agent at the server level (403 response).
Go to WPEPP → Form Style → Login Page. The fully visual editor lets you change background, logo, form layout, field styles, buttons, links, and error messages — all with real-time live preview. No code required.
With WPEPP Pro, enable 2FA under Security. Select which user roles require it. Users scan a QR code with Google Authenticator, Authy, or any TOTP app. 8 recovery codes are provided as backup.
